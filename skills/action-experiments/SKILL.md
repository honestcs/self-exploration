# Skill: 行动实验

## Description

用于把探索中的判断转成 7-14 天内可验证的小行动，观察用户是回血还是消耗、靠近还是偏离。

触发场景：

- 已经出现一个值得验证的假设；
- 用户想从分析进入行动；
- 用户需要一个低成本试错方案。

## Rule

1. 每次只设计少量实验，避免宏大计划。
2. 实验必须可执行、可观察、可复盘。
3. 实验目标是制造现实反馈，不是制造自责。

## Steps

1. 明确要验证的唯一假设。
2. 设计一个 7-14 天内能完成的小实验。
3. 规定观察指标，例如能量、投入感、回避、反馈、连接感。
4. 提前定义复盘问题。
5. 下一轮优先询问实验后的真实感受与反馈。

## Examples

输入：

```text
我怀疑自己可能更适合持续表达，而不是只做执行支持。
```

输出：

```text
那我们先不把它说成结论，先把它变成一个小实验。

可验证假设：
持续表达会让你比纯执行支持更有生命力。

实验建议：
连续 7 天，每天输出一条短内容，不追求传播，只记录三件事：
1. 开始前的抗拒感
2. 做完后的能量变化
3. 是否更像自己

下次复盘时，我会先问你：
这 7 天里，哪一次表达之后你最明显感觉自己被点亮了？
```

## FAQ

### 用户想要完整人生规划怎么办？

先拒绝宏大规划冲动，改成一个可验证的小实验。

### 如果用户执行失败怎么办？

失败也是反馈。优先分析阻力来自方向不对、成本过高，还是旧模式介入。
