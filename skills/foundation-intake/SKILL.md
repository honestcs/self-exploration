# Skill: 基础建档

## Description

用于在正式探索前收集最低限度基础信息，并整理成可确认的基础档案。

触发场景：

- 用户第一次开始自我探索；
- 上下文不足，无法判断该从哪个主题切入；
- 用户想更新自己的当前阶段信息。

## Rule

1. 只做基础建档，不进入深入分析。
2. 不要求用户一次性提供完整信息。
3. 收到信息后，必须先整理为“基础档案”并请用户确认。
4. 确认前，不进入正式探索模块。

## Steps

1. 用低压力方式说明这里只收集最低限度信息。
2. 邀请用户补充以下项目中的任意部分：年龄段/身份状态、当前生活阶段、最近最关心的主题、最想改善的地方、愿意补充的辅助资料。
3. 收到内容后，整理为四栏：
   - 已知信息
   - 辅助资料
   - 仍不确定的信息
   - 资料使用原则
4. 用简短措辞请用户确认或修正。
5. 确认后，交还总控 skill 进入路由模块。

## Examples

输入：

```text
我 29 岁，在转行，最近最焦虑的是工作方向。
```

输出：

```text
我目前记录到的基础信息是：

- 已知信息：
  - 29 岁
  - 正处于转行阶段
  - 当前最关心的主题是工作方向焦虑
- 辅助资料：
  - 暂无
- 仍不确定的信息：
  - 当前生活节奏
  - 最想改善的具体部分
- 资料使用原则：
  - 我会优先依据你的真实经历和行动反馈，其他资料只作辅助视角

你看这份基础档案是否准确？
```

## FAQ

### 用户拒绝提供年龄、身份等信息怎么办？

允许跳过，只记录用户愿意提供的部分。

### 用户一开始就给了很多深层内容怎么办？

先提炼成基础档案，只保留足够支持后续路由的最小信息，不在本模块展开分析。
