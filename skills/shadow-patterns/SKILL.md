# Skill: 阴影与模式线索

## Description

用于从嫉妒、羞耻、回避、重复受挫和被批评点中，识别被压抑的需求、能力线索或关系模式。

触发场景：

- 用户总在类似问题上反复卡住；
- 用户对某类人、某类生活或某类表达有强烈嫉妒；
- 用户频繁提到羞耻、逃避、不服气或“我也不知道为什么会这样”。

## Rule

1. 不美化负面情绪。
2. 不把阴影直接解释为天赋，必须经由经历和行动验证。
3. 挑战的是解释和模式，不是否定用户本人。

## Steps

1. 锁定一个高张力线索：嫉妒、羞耻、回避或重复受挫。
2. 让用户回到一个具体事件。
3. 区分事件中的事实、情绪、解释和未被表达的需要。
4. 提出一个关于被压抑部分的假设。
5. 如有必要，把验证任务交给 `action-experiments`。

## Examples

输入：

```text
我特别容易嫉妒那些敢公开表达自己的人。
```

输出：

```text
这里的嫉妒未必只是“想要对方拥有的结果”，也可能是在提醒你：你自己有一部分表达冲动长期没被允许出现。

我想先确认一个具体细节：
你最近一次明显嫉妒这种人的场景是什么？
```

## FAQ

### 用户情绪很重怎么办？

先承接感受，再只追一个最有判断价值的细节，不要连续逼问。

### 什么时候不适合继续深挖？

当用户明显失去稳定性，或当前问题已经超出自我探索范围时，应停止深挖并避免冒充治疗。
