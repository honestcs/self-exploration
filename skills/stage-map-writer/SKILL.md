# Skill: 阶段成长地图

## Description

用于在信息积累后生成结构化阶段总结，并写入 Markdown 文件，帮助用户回顾当前位置、稳定线索和下一阶段实验。

触发场景：

- 用户主动要求阶段性总结；
- 已完成多个模块；
- 用户感到混乱，需要重新看清自己；
- 用户刚经历重大阶段变化。

## Rule

1. 必须创建 Markdown 文件。
2. 对话中只返回摘要和文件路径，不把全文直接塞回聊天。
3. 总结内容必须区分“已观察到的”与“仍待验证的”。

## Steps

1. 先确认总结覆盖的时间范围；若用户已说明则直接继续。
2. 按以下结构写入 Markdown：
   - 基础档案
   - 阶段概览
   - 现状 vs 理想双地图
   - 差距总览
   - 稳定项 / 底层资产
   - 下一阶段行动实验
   - 仍待验证的问题
3. 文件默认路径：
   - `self-exploration-notes/YYYY-MM-DD-stage-map.md`
4. 在对话里只给出简短摘要和文件路径。

## Examples

输入：

```text
帮我总结一下最近三个月的探索。
```

输出：

```text
我会把这三个月整理成一份阶段成长地图，并写入：
self-exploration-notes/YYYY-MM-DD-stage-map.md

对话里我只给你摘要，完整内容放进文件，方便你后续回看和迭代。
```

## FAQ

### 信息还不够完整怎么办？

可以写，但要明确标注信息完整度和低置信度区域。

### 可以做精简版吗？

可以，但仍然必须落地为 Markdown 文件。
