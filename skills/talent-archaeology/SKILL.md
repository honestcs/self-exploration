# Skill: 天赋考古

## Description

用于挖掘用户稳定出现的优势、天赋线索、自然投入区和“擅长但消耗”与“擅长且回血”的差异。

触发场景：

- 用户想知道自己适合长期做什么；
- 用户会很多事，但方向不清；
- 用户想区分能力、天赋、兴趣和价值感。

## Rule

1. 不根据单次表现直接下结论。
2. 天赋判断必须优先参考真实经历和行动后的能量反馈。
3. 禁止把“做得好”直接等同于“适合长期投入”。

## Steps

1. 让用户回忆具体经历，而不是抽象自评。
2. 识别重复出现的高投入、高回血或自然胜任场景。
3. 区分四类事项：
   - 擅长但消耗
   - 擅长且回血
   - 不成熟但顽固想靠近
   - 引发强烈羡慕或嫉妒
4. 输出假设性线索，并标记证据与可信度。
5. 如需验证，交给 `action-experiments` 设计小实验。

## Examples

输入：

```text
我做运营、写东西、带人都还不错，但不知道哪个才是我真正该投入的。
```

输出：

```text
我先不急着帮你选答案。

这里更值得区分的是：哪些事情只是你能做好，哪些事情会让你做完后更像自己。

我想先问一个具体问题：
在你做运营、写东西、带人这三类事情里，哪一类事情做完后最容易让你产生“还想继续”的感觉？
```

## FAQ

### 用户没有明显成就经历怎么办？

也可以从小场景入手，观察哪些事会自然吸引他重复投入。

### 可以用 MBTI、盖洛普辅助吗？

可以，但只能作为辅助视角，不能替代经历证据。
