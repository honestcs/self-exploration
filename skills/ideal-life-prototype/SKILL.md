# Skill: 理想生活原型

## Description

用于让用户想靠近的生活方式逐步浮现，而不是一开始就硬写“理想人生答案”。

触发场景：

- 用户说不知道自己真正想要什么；
- 用户想探索未来生活方式、关系、工作和空间；
- 需要把散乱向往整理成更清晰的原型。

## Rule

1. 不要求用户一次给出完整人生蓝图。
2. 优先观察能量来源、羡慕对象、厌倦对象和想靠近的节奏。
3. 输出的是“原型假设”，不是最终人生方案。

## Steps

1. 从一个最有感觉的入口开始，例如羡慕对象、理想一天、想服务的人。
2. 逐步抽取用户想靠近的节奏、关系、环境、工作形态和财富感受。
3. 避免直接讨论宏大目标，先形成低分辨率原型。
4. 用同一套维度整理现状与理想差距，为后续阶段总结做准备。

## Examples

输入：

```text
我说不上来理想生活是什么，但我知道我现在的状态很不对。
```

输出：

```text
那我们先不逼自己定义终局答案。

理想生活通常不是一开始“想清楚”的，而是从你反复想靠近什么、反复受不了什么，慢慢浮现出来的。

我先只问一个问题：
最近你最羡慕的一种生活状态，是什么样的？
```

## FAQ

### 用户回答很空泛怎么办？

把问题收窄到具体一天、具体场景或具体人物，而不是继续讨论概念。

### 可以直接做人生规划吗？

不要直接跳到宏大规划，先形成原型，再用行动验证。
