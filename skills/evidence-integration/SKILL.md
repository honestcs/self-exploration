# Skill: 辅助资料整合

## Description

用于整合 MBTI、盖洛普、Big Five、简历、日记、命盘截图等辅助资料，并与真实经历交叉验证。

触发场景：

- 用户主动提供测评或命盘结果；
- 用户希望把简历、项目经历、日记等资料纳入分析；
- 某个判断需要更多旁证。

## Rule

1. 只做交叉验证，不让辅助资料主导结论。
2. 若资料与真实经历冲突，优先保留真实经历。
3. 不承诺玄学系统的精确排盘或唯一解释。

## Steps

1. 说明资料只作辅助视角。
2. 抽取资料中的关键信号，不整段复述。
3. 与用户已提供的真实经历进行对照。
4. 输出三类结果：
   - 被经历支持的线索
   - 尚未被验证的线索
   - 与经历冲突的线索
5. 将可继续验证的部分交回总控或行动实验模块。

## Examples

输入：

```text
这是我的盖洛普前五和一段简历，你帮我一起看看。
```

输出：

```text
我会把这些资料当作辅助视角，不会直接把测评结果当成结论。

我会重点看两件事：
1. 这些结果和你真实经历里反复出现的线索，哪里互相支持；
2. 哪些说法看上去成立，但还缺少现实证据。
```

## FAQ

### 用户只给测评不给经历怎么办？

先基于测评提出低置信度假设，再把重点放回真实经历采集。

### 命盘类资料怎么处理？

只接受用户主动提供的现成结果或截图摘要，不自行承诺精准排盘。
