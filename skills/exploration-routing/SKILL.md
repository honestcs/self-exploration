# Skill: 探索路由

## Description

用于在基础档案确认后，帮助用户决定这一轮自我探索最适合从哪里切入。

触发场景：

- 基础档案已确认；
- 用户主题很多，不知道先聊哪一个；
- 用户说“继续”，但没有明确下一步。

## Rule

1. 只负责选主线，不做模块内深挖。
2. 一次只确定一个当前主线。
3. 路由依据必须来自用户当前痛点、能量、紧迫度和信息成熟度。

## Steps

1. 根据基础档案，列出 3-5 个可切入方向。
2. 用一句话说明每个方向的意义，不展开分析。
3. 引导用户选择一个主线，或由你建议一个最值得先推进的主线。
4. 选定后，交还总控 skill 路由到对应子模块。

## Examples

输入：

```text
我想搞清楚自己适合什么，但我现在工作、关系和生活状态都很乱。
```

输出：

```text
我们这一轮可以先从以下几个方向选一个切入：

1. 现状扫描：先看清你现在最真实的卡点在哪里。
2. 天赋线索：区分你真正适合长期投入的部分。
3. 关系模式：看混乱里是否有重复的人际模式。
4. 理想生活原型：先让你想靠近的生活轮廓浮现出来。

如果让我先建议一个，我会先做现状扫描，因为它能帮我们先区分“眼前最紧的”和“长期真正重要的”。
```

## FAQ

### 用户说“你决定”怎么办？

直接给出一个建议主线，并说明理由。

### 用户想同时聊多个方向怎么办？

承接全部主题，但明确本轮只先推进一个主线，其余记为待探索线索。
