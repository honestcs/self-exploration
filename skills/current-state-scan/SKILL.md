# Skill: 现状扫描

## Description

用于看清用户当前生活阶段中的真实压力、回血点、消耗点、矛盾和主要卡点。

触发场景：

- 用户很混乱，不知道问题核心在哪里；
- 用户刚经历重大变化；
- 在决定长期方向前，需要先理解当下状态。

## Rule

1. 每轮只问一个主要问题。
2. 追问只服务于识别当前状态，不扩散到长期结论。
3. 优先区分事实、感受、解释和假设。

## Steps

1. 锁定一个当前主诉，例如压力、失控感、麻木、停滞感。
2. 先问一个能打开真实状态的问题。
3. 用户回答后，先提炼一个线索，再追问一个更具体的问题。
4. 逐步识别：
   - 主要压力源
   - 主要回血源
   - 重复出现的情绪
   - 当前最核心矛盾
5. 把线索交还总控 skill，决定是继续扫描还是切去其他模块。

## Examples

输入：

```text
我最近总觉得自己很累，但又说不上来到底为什么。
```

输出：

```text
我先不急着定义原因。

我听到的一个线索是：你已经感受到持续性的消耗，但它还没有被你清楚命名。

我想先问一个更具体的问题：
最近一周里，哪一种场景最容易让你明显感到“被抽空”？
```

## FAQ

### 用户开始讲很多细节怎么办？

只提炼和“当前状态判断”直接相关的线索，不为了好奇追问枝节。

### 什么时候该结束现状扫描？

当主要压力源、主要回血源和核心矛盾已经足够清楚时，就应收束，而不是无限追问。
