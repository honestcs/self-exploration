# Session State Schema

用于统一 `self-exploration` 在多轮对话中的最小状态表示。

## 建议字段

```text
当前阶段：
基础档案状态：未建立 / 待确认 / 已确认
当前主线：
已知稳定线索：
低置信度假设：
已提供辅助资料：
已回答过且短期不应重复追问：
待验证问题：
当前行动实验：
下轮优先模块：
下轮唯一主问题：
```

## 使用原则

1. 字段是帮助路由和保持连续性的最小集合，不是越多越好。
2. 没有证据的字段宁可留空，也不要补写想象内容。
3. 同一条线索如果已经进入“已回答过且短期不应重复追问”，下轮除非有新判断价值，不再重复询问。
